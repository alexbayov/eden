## 2. Граница scope плана

Этот план ведёт проект от текущего M3-D alpha к **release candidate MVP** по границам [`20-mvp-scope-and-roadmap.md`](20-mvp-scope-and-roadmap.md). **Правка 28 августа 2026: прежняя формулировка цели («4 зоны, 6 типов врагов, 7 оружий, 8 ресурсов, 3 уровня базы») снята решением D-03**, которое утвердило объём первого релиза как **2 зоны по 3 encounter**. Фактический утверждённый объём: 2 зоны / 6 encounter, 6 типов врагов, 4 оружия, 3 ресурса в обороте, 3 уровня трёх узлов базы. Числа «7 оружий» и «8 ресурсов» были целью, а не измерением, и как цель первого релиза отменены — расширение каталога уходит в post-MVP.

**Внутри плана:** инженерная реализация, QA-инфраструктура, баланс, интеграция контента и ассетов, подготовка релиза.

**Вне плана:** производство арта и звука (внешняя работа, см. §10), финальные тексты нарратива, платформенные юридические/консент-требования, серверная часть (cloud save, authoritative leaderboards, anti-tamper).

**Допущение по ресурсам:** один разработчик full-time, владелец продукта — part-time для решений. План **последовательный**: параллельные треки не запланированы, потому что почти каждый пакет зависит от QA-инфраструктуры и решений по балансу.

## 8. Definition of Ready / Definition of Done

### Definition of Ready (тикет можно брать)

1. Есть цель одним предложением и явный источник (документ или файл кода).
2. Перечислено, что **вне** scope тикета.
3. Контракт данных/API описан или явно указано, что не меняется.
4. Критерии приёмки проверяемы автоматически или ручным скриптом.
5. Все зависимости закрыты, все нужные решения владельца приняты.
6. Указана оценка S/M/L.
7. Если тикет требует ассетов или платформенной спецификации — они уже поступили.

### Definition of Done (тикет закрыт)

1. `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, `npm run analyze:budget` зелёные.
2. Новое поведение покрыто тестом, который падает без изменения.
3. Если тикет затрагивает UI/ввод — есть E2E или DOM-проверка, а не только статическая.
4. Если тикет затрагивает числа — есть прогон симулятора или граничный тест.
5. Обновлены затронутые документы 09–24 и статус в `00-index.md`.
6. Изменение закоммичено в ветке и отправлено в PR; PR описывает что проверено и **что не проверено**.
7. В документах нет утверждений о браузерной/устройственной проверке, которой не было.
8. Временные файлы и отладочный код удалены.
