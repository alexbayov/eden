# 15 — Audio Design

**Статус:** 🟢 v1.0.

## MVP audio matrix

| Слой | Контент | Правило |
|---|---|---|
| UI | click, confirm, error | короткий, различимый |
| Бой | выстрелы по классу, попадание, промах, броня, осечка | сигнал результата без громкости-спама |
| Статус | stun, blind, immobilize, OW | отдельный узнаваемый cue |
| Мир | ветер, металл, дальний сигнал | loop ≤60 с, низкая интенсивность |
| Музыка | база, исследование, бой, финал | crossfade, mute доступен |

Приоритет: gameplay feedback > ambience > music. Первый playable может использовать временные лицензированные/синтезированные локальные ассеты, но список лицензий обязателен.

## Acceptance criteria

- Все боевые состояния имеют звуковой и визуальный/текстовый feedback.
- Музыку и SFX можно раздельно выключить; состояние сохраняется.
- Нет автозапуска звука до пользовательского взаимодействия.
- Mobile-микс не клиппует и не мешает речи/тексту.

## Открытые решения

- Музыкальный язык и нужен ли голос отца.
- Финальный формат исходников и бюджет записей.

## Post-MVP

Динамический stem-mix, фракционные музыкальные темы и полноценные аудиодневники.
