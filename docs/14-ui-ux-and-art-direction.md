# 14 — UI/UX & Art Direction

**Статус:** 🟢 v1.0. Desktop и mobile входят с первого playable.

## UX principles

1. Один главный CTA на экран.
2. Touch target минимум 44 px, текст не меньше 14 px в HUD.
3. Критическая информация дублируется цветом, формой и текстом.
4. Бой не требует hover: long-tap открывает radial body-part menu.
5. Ошибка объясняется причиной и следующим действием.

## Screens MVP

| Экран | Обязательное | Acceptance |
|---|---|---|
| База | узлы, stash, миссия, цель | возврат к вылазке ≤3 кликов |
| Planner | риск, цель, экипировка | предупреждения до старта |
| Бой | grid, HP/AP, 6 частей, breakdown, OW | действие понятно за 2 с |
| Результат | XP, лут, смерть/победа | итог нельзя пропустить |
| Настройки | звук, масштаб, контраст | сохраняются локально |

## Visual system

Палитра: охра/пыль/бетон + холодный синий интерфейс; красный только опасность. Изометрия статичная, 2D, читаемые силуэты. Состояния: normal/hover/selected/danger/disabled. Арт не маскирует клетку, LOS или укрытие.

## Acceptance criteria

- Все экраны проходят 360×640 и desktop 1280×720 без перекрытия CTA.
- Шесть частей тела доступны одной рукой.
- Контраст текста/индикаторов проверен вручную; цвет не единственный канал.
- Прототипный HUD и production UI имеют общий token-файл после реализации.

## Открытые решения

- Точные шрифты и лицензии локальных ассетов.
- Финальный breakpoint и safe-area для webview.

## Post-MVP

Анимации базы, дополнительные темы доступности, drag inventory и декоративная кастомизация.
