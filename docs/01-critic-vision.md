## B. Что мы делаем **правильно** относительно рынка

1. **Ниша не занята.** На Яндекс.Играх/VK Play нет тактической постапок-RPG такого уровня амбиций. Существующие проекты — либо казуалки, либо клоны farmer/idle. Есть окно.
2. **Комбинация базы + вылазок + прицельного боя** — редкая. Обычно эти системы разводят: State of Decay = база + real-time; Fallout = вылазки + пошаговый бой без базы; DayR = база + мобилка без пошагового боя. Мы синтезируем.
3. **Лорный респавн с ценой** — уникально. Death Stranding сделал это в AAA, никто не адаптировал в CRPG.
4. **10-15ч MVP скоуп** — реалистично для одиночного разработчика с ИИ-агентами. Fallout 1 — 30ч, ATOM RPG — 60ч. Мы не пытаемся сделать блокбастер.
5. **Реальное оружие в постсоветской эстетике** — сильный крючок для русскоязычной аудитории. STALKER это знает.

## C. Где мы рискуем — **красные флаги**

### Флаг C1: Слишком много механик для одного разработчика

Даже с ИИ-агентами: пошаговый бой + прицел частей + крафт + модификации + база + вылазки + прогрессия L2-уровня — это **6 отдельных сложных систем**. Underrail разрабатывался Stygian Software (2-3 человека) **12 лет**. ATOM RPG — 5 лет и команда из 8. Даже с ИИ-ассистом, для одного человека это огромный скоуп.

**Риск:** проект утонет в объёме, MVP не будет играбельным даже через год.

**Рекомендация критика:**
- жёстко сократить скоуп **каждой** системы для MVP;
- MVP-крафт = 5-10 рецептов, а не 50;
- MVP-модификации = 3-4 типа (глушитель, коллиматор, магазин), а не 15;
- MVP-база = 3-4 апгрейда, а не 10;
- MVP-локаций = 3-4, а не 15;
- проверить каждую систему на "можно ли выкинуть в MVP и добавить пост-релиз?"

### Флаг C2: Браузерная платформа vs глубина системы

Яндекс.Игры оптимизированы под сессии 5-15 минут. Мы делаем игру с длинными кривыми прогрессии (L2-стиль), пошаговыми боями (по 3-10 минут каждый), и глубоким крафтом. **Это конфликт форматов.**

**Риск:** игрок открывает игру на 10 минут в обед, попадает в бой, не успевает его закончить — фрустрация; или заходит, крафтит один предмет, выходит — нет чувства прогресса.

**Рекомендация критика:**
- каждая сессия должна давать **гарантированный прогресс** (даже 5-минутная): 1 бой законченный + 1 крафт + 1 находка;
- средний бой не должен превышать 3-4 минуты (5-7 ходов);
- автосейв везде;
- система "быстрый крафт" по 30 секунд для мелких предметов;
- вылазка должна быть разделена на "чекпоинты" по 10 минут, чтобы игрок мог выйти с чистой совестью.

**УПДАТ v0.2:** решено через систему энергии + чекпоинты (см. раздел 03).

### Флаг C3: L2-прогрессия в 10-15-часовой игре

Lineage 2 работает потому что в него играют **сотни часов**. Кривые опыта L2 в 10-15-часовой игре — это либо игрок дойдёт до 10 уровня, либо будет фрустрирован.

**Рекомендация критика:**
- уточнить: имеется в виду **чувство** прогрессии, а **не** буквальные кривые L2;
- целевой уровень к концу MVP: ~15-20 (не 80);
- каждый уровень должен разблокировать что-то ощутимое: перк, атрибут, новый крафт;
- избежать "уровней-заполнителей".

**УПДАТ v0.2:** взято "ощущение" L2, не буквальные кривые. За уровень: 1 очко навыка + разблокировка (зон/оружия/крафта).

### Флаг C4: "Смерть без унижения" — легко скатиться в "смерть без последствий"

Death Stranding работал потому что смерть была визуально драматичной и лорно значимой. В браузерной 2D-игре с быстрым респавном есть риск, что смерть станет рутиной.

**Рекомендация критика:**
- потери на смерти должны быть **чувствительными, но не catastrophic**;
- предлагаемая формула:
  - -20% опыта до следующего уровня (не текущий уровень!)
  - -1 случайный редкий ресурс + -30% обычных ресурсов
  - +6 игровых часов (мир идёт вперёд)
  - визуальный/лорный шрам — усиливает эмоцию;
- в MVP: смерть на low-level = маленькая цена; на high-level = серьёзная. Кривая растёт.

**УПДАТ v0.2:** формула принята + добавлено -10 энергии для следующего вылаза.

### Флаг C5: Отсутствие сюжетного якоря

Vision описывает механику ("ищет Эдем") но не даёт сюжетного крючка. Fallout работает потому что "спаси Убежище 13". Metro — "спаси метро". У нас пока слабо.

**Рекомендация критика:**
- нужен конкретный **inciting incident** в первые 10-15 минут;
- нужен **antagonist**;
- Эдем должен быть **конкретным** (не абстракцией).

**УПДАТ v0.2:** выбрана комбинация A (Время) + B (Мародёры). Прорабатывается в разделе 13.

### Флаг C6: "Реальное оружие" — юридический риск

Использование настоящих названий оружия может создать проблемы:
- **Kalashnikov Concern** активно защищает торговую марку "АК".
- Яндекс.Игры может отклонить проект по правилам модерации.

**Рекомендация критика:**
- **вариант А** (безопасный): фиктивные имена ("АК-47" → "АСК-47");
- **вариант Б** (рисковый): реальные названия — не рекомендую;
- **вариант В** (гибрид): советские классические (ПМ, АКМ, ТТ, СВТ, ППШ, Мосинка) — public domain, риска почти нет. Западное современное — фиктивные имена.

**УПДАТ v0.2:** принят вариант В.

## D. Где нам стоит **украсть** идеи у референсов

- **из Cold Zero:** система стелса с оглушением/несмертельным устранением, награда за stealth-прохождение (бонус XP).
- **из Fallout 2:** система репутации (Karma) — даже минимальная, добавляет глубины.
- **из ATOM RPG:** система страха / морали персонажа при виде трупов/крови.
- **из Underrail:** глубокая система крафта с "качеством" материалов (разные варианты одного рецепта).
- **из Encased:** система "аномалий" в мире — точки интереса с уникальным лутом.
- **из Jagged Alliance 2:** реалистичная система урона (кровопотеря, шок, критические ранения).
- **из State of Decay 2:** база с "настроением" и потребностями.

## E. Ключевые претензии критика к первой версии Vision

1. **Vision слишком амбициозный для одного разработчика.** Скоуп надо резать в 2-3 раза для MVP. → **Не решено ещё, нужен MVP scope pass в разделе 20.**
2. **Нет чёткого нарративного крючка.** → **Решено v0.2: A+B антагонисты.**
3. **Юридика оружия не проработана.** → **Решено v0.2: вариант В.**
4. **Сессия vs глубина — противоречие форматов.** → **Решено v0.2: энергия + ежедневки + чекпоинты.**
5. **"Как в L2"** — конкретизировано. → **Решено v0.2.**
6. **Anti-vision слабоват.** → **Расширен в v0.2.**
