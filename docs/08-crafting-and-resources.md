## Изменения v0.2 (относительно v0.1)

1. **Пункт улучшения ресурсов работает в РЕАЛЬНЫХ часах**, не игровых. Партия готова к следующей сессии (2-4 часа реального времени).
2. **Разборка максимум 75%** (было 90%). Формула: `50% + (Repair × 0.25%)`.
3. **Пружины и артефакт-компоненты НЕ возвращаются** при разборке (ломаются).
4. **Электронные чипы, керамика, линзы — 30% шанс возврата** при разборке (иначе ломаются).
5. **Крит-крафт визуально ощутим:** особая анимация, звук, экран с надписью, +20-30% к статам (было 15-25%).
6. **Ачивмент "Мастер удачи":** 10 крит-крафтов = +5% к базовому шансу навсегда.
7. **Мастер-рецепты имеют +2% к крит-крафт шансу.**
8. **Мини-выбор перед крафтом:** ползунок приоритета статов (Урон / Точность / Стелс / Крит), для мастер-рецептов — выбор варианта модификации.
9. **UI-сравнение "Ремонт vs Разборка"** при hover на найденный предмет.
10. **Sink-механики против ресурсного флуда:** штраф на скорость поиска в сундуке при 500+ ресурсов одного типа.
11. **Задел на 200-350 донат-монет за MVP-курс** для F2P-игрока (детали в разделе 15).

## 8.0 Ключевые принципы

1. **Гибридные рецепты.** Формула + модификаторы от навыка/удачи/качества.
2. **Многоуровневые ресурсы.** 3 тира для ключевых, 2 для базовых.
3. **Разблокировка чертежами + навыками.** Три уровня доступа.
4. **Единый верстак с 5 уровнями (MVP).** Простая архитектура.
5. **Мастер-рецепты как F2P монетизация.** Стабильный бонус.
6. **Крит-крафт как награда за Luck.** Визуально ощутим.
7. **Разборка даёт ресурсы обратно.** Но не все, максимум 75%.

### 8.2.2 Пункт улучшения ресурсов — v0.2 (реальное время)

С уровнем базы **3+** появляется автоматический пункт улучшения:

**Время в реальных часах** (не игровых). Партия готова к следующей сессии.

| Улучшение | Время реальное | Партия | Стоимость |
|---|---|---|---|
| Металлолом ×5 → Металл ×1 | Мгновенно на верстаке 2+ | 1 партия = 1 Металл | 5 Металлолома |
| Тряпьё ×5 → Ткань ×1 | Мгновенно на верстаке 2+ | 1 партия = 1 Ткань | 5 Тряпья |
| Сырая кожа ×3 → Выделанная кожа ×1 | Мгновенно на верстаке 2+ | 1 партия = 1 Выделанная | 3 Сырых + 1 Химия |
| **Металл ×3 → Сталь ×1** | **2-3 часа реального времени** | 1 партия = 1 Сталь | 3 Металла |
| **Ткань ×3 + Химия ×1 → Кевлар-волокно ×1** | **3-4 часа реального времени** | 1 партия | 3 Ткани + 1 Химия |
| **Выделанная кожа ×2 + Химия ×1 → Толстая кожа ×1** | **1-1.5 часа реального времени** | 1 партия | 2 Выделанных + 1 Химия |

**Как это работает:**
1. Игрок закладывает партию в пункт улучшения → закрывает игру.
2. **Партия готова через N часов реального времени** (даже если игрок оффлайн).
3. Игрок возвращается — партия уже готова, забирает.

**Слоты одновременных партий:**
- База 3: 1 слот.
- База 4: 2 слота.
- База 5: 3 слота.
- **Premium:** +1 слот всегда.

**Ускорение партии:**
- **Premium:** -50% времени партии.
- **Донат-монеты:** 10 монет = -50% времени, 20 монет = мгновенное завершение.

### 8.2.3 Post-MVP расширение — 4 специализированных верстака

В обновлениях после MVP: Оружейный / Слесарный / Химический / Швейный. Функционал MVP-верстака сохраняется, добавляются новые рецепты.

### 8.3.1 Где брать чертежи

- Сундуки в мире — обычные чертежи.
- Элитные противники — 20% шанс редкого.
- Боссы — 80% гарантия редкого.
- Сюжетные квесты — эксклюзивные.
- Премиум-паки — 1-2 редких + донат-монеты.
- **Инстансы дня** — 10-30% шанс на чертёж.

## 8.4 Гибридные рецепты — формула — v0.2 (мини-выбор)

### 8.4.1 Три стадии крафта (без изменений)

**1. Проверка ресурсов.**
**2. Бросок успеха:**
```
finalSuccess = baseSuccess + (Repair × 0.4) + (Intelligence × 2) + qualityBonus + luckModifier
```
**3. При провале:** ресурсы возвращаются частично.
```
returnRate = 30% + (Repair × 0.4)  # 30-70%
```

### 8.4.2 Мини-выбор перед крафтом — v0.2 (новое)

**Перед нажатием "Крафт", игрок видит панель приоритетов:**

- **Ползунок:** [Урон 25% | Точность 25% | Стелс 25% | Крит 25%] по умолчанию равномерно.
- Игрок может двигать ползунки: до +2% в один стат при 0% в остальных.
- **Ограничение:** сумма всех стат-бонусов не может превышать полный statBonus, вычисленный из Repair.

**Пример:**
- Игрок с Repair 100 крафтит АКМ. `statBonus = +7.5%`.
- Приоритет "Урон": +7.5% в урон, 0 в остальные.
- Приоритет "Урон 3% + Точность 2.5% + Крит 2%": суммарно = 7.5%.

**Для базовых рецептов** (Шершень, Оса-2, аптечки, простые патроны) — **мини-выбор пропускается**, идёт равномерное распределение.

**Для мастер-рецептов** — **дополнительный выбор варианта модификации**:
- **Мастер-АКМ:** выбор из [Точная (+10% точности) / Штурмовая (+10% урона) / Быстрая (-1 AP на действия)].
- **Мастер-Мосинка:** [Тактическая (+15% крит) / Дальнобойная (+3 клетки дальности) / Стелс (совместимость с глушителем без штрафа урона)].
- **Мастер-Кевлар:** [Тяжёлая (+15% DR) / Лёгкая (без AP-штрафа) / Универсальная (+5% DR + сопротивление криту)].

Даёт билд-глубину без комбинаторного взрыва.

### 8.4.3 Результат крафта варьируется

```
statBonus = (Repair - 50) × 0.15% + (Luck - 5) × 0.3% + qualityBonus
```

- Repair 100 + LUC 10 = +9% к статам.
- Repair 50 + LUC 5 = 0% (стандарт).
- Repair 20 + LUC 3 = -5.1% ("плохо сделанный").

**qualityBonus:** +5% если все ресурсы улучшенных тиров (Сталь вместо Металла и т.д.).

### 8.4.4 Крит-крафт — v0.2 (усилен)

```
critCraftChance = 3% + (Luck × 1.2%) + (masterRecipeBonus)

masterRecipeBonus = +2% для мастер-рецептов
```

От 4.2% при LUC 1 до **17% при LUC 10 + мастер-рецепт**.

**Крит-крафт даёт +20-30% к статам** сверх обычного модификатора (было 15-25%).

**Визуальный отклик v0.2:**
- Особая анимация верстака (искры, дым).
- Особый звук (характерный "звонкий" звук молота).
- Экран с надписью "**КРИТИЧЕСКИЙ КРАФТ**" + результат.
- В инвентаре предмет получает **специальную метку "★"** и золотую рамку.

**Ачивмент "Мастер удачи":** после 10 крит-крафтов игрок получает **+5% к базовому critCraftChance навсегда**.

**UI до нажатия "Крафт":**
- Шанс успеха: 78%.
- При успехе: +2.3% к характеристикам (с выбранными приоритетами).
- Шанс крит-крафт: 17%.
- При крит-крафте: +28% к характеристикам.

### 8.4.5 Мастер-рецепты — v0.2 (усилены с крит-бонусом)

Требуют:
- Обычный рецепт открыт.
- Мастер-чертёж (редкий лут / премиум).
- **20-50 донат-монет за использование.**

Даёт:
- Стабильный +5-15% к характеристикам.
- +15% к шансу успеха.
- **+2% к крит-крафту** (v0.2 новое).
- **Выбор варианта модификации** (v0.2 новое).
- При провале — обычная версия, донат-монеты возвращаются.

## 8.5 Разборка (breakdown) — v0.2 (пересмотрено)

### 8.5.1 Разборка оружия — v0.2

- Формула возврата: **`50% + (Repair × 0.25%)`**. Максимум 75% при Repair 100.
- **Пружины не возвращаются никогда** (ломаются).
- **Артефакт-компоненты не возвращаются никогда.**
- **Электронные чипы, керамика, линзы:** 30% шанс возврата (иначе ломаются).

**Пример АКМ (60 Металла + 30 Механики + 10 Дерева + 1 Пружина):**
- Repair 100 = 75% возврат от базовых → **45 Металла + 22 Механики + 7 Дерева + 0 Пружин**.
- Repair 50 = 62.5% возврат → **37 Металла + 18 Механики + 6 Дерева + 0 Пружин**.
- Repair 0 = 50% возврат → **30 Металла + 15 Механики + 5 Дерева + 0 Пружин**.

### 8.5.2 Разборка модификаций — v0.2

- Успех снятия: `70% + (Repair × 0.3%)` (до 100% при Repair 100).
- При успехе — мод в инвентарь.
- При провале — мод ломается, ресурсы возвращаются частично (40% + Repair×0.3%).

### 8.5.3 Разборка брони

- Кожаная броня: 50-75% ткани/кожи (по формуле возврата).
- Тактический жилет: 40-70% + шанс керамики (30% при разборке).
- Кевлар: 30-60% + гарантия керамики (в 30% случаев).
- Экзо: 20-50% + гарантия чипа/пружины (в 30% случаев, только если пружина есть в оригинале).

### 8.5.4 UI сравнения "Ремонт vs Разборка" — v0.2 новое

При hover на найденный предмет в мире или в рюкзаке:

```
ПМ, состояние 40%

▶ Ремонт: 5 Металла + 2 Механики (стоит 5 ресурсов)
   Восстанавливает до 90-100% состояния.

▶ Разборка: получишь ~9 Металла + 5 Механики (стоит 0 ресурсов)
   Уничтожает оружие безвозвратно.

💡 Рекомендация: Ремонт (сохраняет полезное оружие).
```

Для сломанного оружия (0% состояния) с редким статусом:
```
💡 Рекомендация: Разборка (оружие бесполезно, ресурсы полезны).
```

Игрок сам решает по своим приоритетам.

## 8.6 Sink-механики против ресурсного флуда — v0.2 (новое)

### 8.6.1 Визуальные штрафы

- В сундуке базы: при 500+ одного ресурса — **штраф на скорость поиска** (юзабилити). Не блокирует крафт, но мотивирует тратить.
- Ресурсы можно расфасовывать по подкатегориям сундука (базы 3+) — меньше штрафа.

### 8.6.2 Механические sink-точки

- **Апгрейд базы потребляет большие партии** ресурсов (см. 8.2.1 и раздел 09).
- **Пункт улучшения потребляет 3-5x базовых** (Металлолом ×5 → Металл ×1).
- **Мастер-рецепты требуют Сталь/Кевлар/Толстую кожу** — их надо готовить в очередях.
- **Крафт мастер-модификаций** — потребляет по 1-2 редких компонента.

### 8.6.3 Post-MVP механики sink

- Торговля с NPC-обменниками (обмен базовых на редкие).
- Плата ресурсами за обучение перкам у "мастеров".
- Реставрация уникальных сюжетных предметов.

## 8.9 Пример полного крафта — v0.2

**АКМ мастер-рецепт (уровень 3, верстак 5):**

**Условия:**
- Ресурсы: 60 Металла + 30 Механики + 10 Дерева + 1 Пружина + мастер-чертёж.
- Стоимость: 20 донат-монет.
- Игрок: Repair 60, INT 6, LUC 7, выбор варианта "Штурмовая" (+10% урона).

**Расчёт:**
- baseSuccess = 65 (65% для мастер).
- Repair × 0.4 = +24.
- INT × 2 = +12.
- qualityBonus = 0 (используется базовый Металл, не Сталь).
- luckModifier = +0.6% (LUC 7 - 5 = 2, × 0.3).
- **finalSuccess = 101.6%, капается на 100%.**
- **critCraftChance = 3 + LUC×1.2 + 2% (мастер) = 3 + 8.4 + 2 = 13.4%.**

**Результат при успехе:**
- Обычный АКМ + **фиксированный "Штурмовая" бонус +10% урона**.
- Модификатор от Repair/LUC: +2.4% + +0.6% = +3% сверх обычного.
- **Итог:** АКМ с +10% урона + +3% ко всем статам.

**Результат при крит-крафте (13.4%):**
- **Дополнительный бонус +20-30% к статам сверх обычного.**
- Итоговое: АКМ с +10% урона + +23-33% ко всем статам.
- Особая анимация + метка "★" + золотая рамка + ачивмент прогрессирует.
