# 00 — Critical Audit

**Статус:** 🟡 M3-B current state: strict save validation implemented; browser E2E/performance pending. **Дата:** 17 авг. 2026.

## Фактическая граница текущего M3-B slice

`code/` — не полный production MVP, а M3-B runtime alpha: одна data-driven зона, три encounter, validated runtime map catalog с переключением карт, campaign progression и schema-v4 local save. Exactly-once reward claim подтверждён только для normal application flow. Local offline save защищён от corruption и обычных flow-ошибок строгой валидацией, но **не** защищён от ручного rollback/edit в localStorage. Anti-tamper и authoritative leaderboards потребуют будущего cloud/server save.

M3-B strict runtime-catalog save validation подтверждена; browser E2E и performance QA остаются pending. В полном MVP по-прежнему отсутствуют 4 зоны, полный production-контент, финальная экономика, browser E2E и платформенные интеграции.

`docs/04-combat-system.md` требует отдельной **formula reconciliation** с `code/src/game/combat.ts` до production. Нельзя считать формулы 04 реализованными по наличию прототипа.

## Противоречия, которые нельзя молча переносить

1. **Монетизация:** старые 01/03/05/07/08 допускают силу, темп или преимущество за деньги; действует 16.
2. **Смерть:** 01 описывает -20% до next level, 04 — фиксированные суммы, 05 — 15% с потолком, 07 — escalating loot loss. До решения действует консервативный MVP из 20: первая смерть бесплатна; далее фиксированный безопасный штраф без эскалации.
3. **Броня и экзо:** 04 включает базовую броню по частям в MVP, 06 одновременно относит экзо к финалу и post-MVP. Экзо исключён из первого playable; четыре базовые слоты защиты остаются.
4. **Контент:** «10 зон / 20 оружий / 18 ресурсов» — долгосрочный каталог, не production scope первого релиза.
5. **Платформа:** документы ориентируются на Яндекс.Игры, но совместимость рекламы, покупок, аналитики и облачных сохранений не подтверждена локальными данными. Никакая интеграция не считается утверждённой.
