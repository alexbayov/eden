## 4.0 Ключевые принципы боя

Всё, что здесь описано, должно поддерживать эти принципы. Если противоречит — пересматриваем.

1. **Каждый ход = осмысленное решение.** Никаких "просто атакую", как в JRPG. Игрок всегда взвешивает: куда стрелять, откуда, чем, стоит ли рисковать.
2. **Прицел в части тела = ядро тактики.** Голова = крит; ноги = обездвиживание; руки = сброс оружия; торс = гарантированный урон. Это столп №1 Vision.
3. **Читаемость шансов.** Игрок видит финальный % попадания и понимает, из чего он складывается. Никаких "магических" бросков.
4. **Средний бой = 3-5 минут.** Не MMO-рейд. Быстрая сессия должна давать закрытый бой.
5. **AP-система с быстрыми действиями.** Основа — AP как в Fallout. Плюс "быстрые действия" — не тратят весь ход. **Утверждено владельцем (вариант D).**
6. **Тактика > статистика.** Позиция, укрытие, часть тела, момент — всё это важнее, чем "качай атаку до 100".

## 4.1 Система очков действия (AP)

Гибридная: обычные AP + быстрые действия.

### Обычные AP

- Каждый персонаж начинает ход с **10 AP** (базово).
- Модификаторы:
  - Атрибут "Ловкость" (см. раздел 05): +0.5 AP за каждое очко выше 5 (округление вниз).
  - Уровень усталости (голод/жажда/раны): -1..-3 AP.
  - Броня: тяжёлая броня -1..-2 AP, лёгкая 0, экзоскелет +2.
  - Перк "Спринтёр" (пример): +1 AP.
- Максимум AP на ход: **15**. Минимум: **4** (даже с полным набором штрафов).
- Неиспользованные AP **не переносятся** на следующий ход (иначе появляется абузная тактика "копи ходы").

### Быстрые действия (Free Actions)

Действия, не тратящие AP или тратящие 0.5 (округление в пользу игрока = 0):

- **Смена активного оружия** через быстрый слот (1 раз за ход бесплатно, потом 2 AP)
- **Использование быстрого шприца** (стим, аптечка в быстром слоте — 1 раз за ход бесплатно)
- **Осмотр карты / противника** (проверка HP, статусов, шансов попадания) — всегда бесплатно
- **Речь / крик** (для механик страха и морали) — 1 раз за ход бесплатно
- **Смена позы** (стоя → присед / присед → лёжа) — 1 AP, но не считается "полным действием"

Идея: игрок не должен терять весь ход, чтобы перезарядиться или сменить оружие. Быстрые действия убирают самую бесящую фрустрацию Fallout-стиля.

### Стоимости обычных действий (baseline v0.1)

| Действие | AP |
|---|---|
| Шаг (1 клетка на гриде) | 1 |
| Спринт (2 клетки за 3 AP, но снижает точность след. выстрела -10%) | 3 за 2 клетки |
| Обычная атака (без прицела) | 4 |
| Прицельная атака: **голова** | 6 |
| Прицельная атака: **торс** | 4 |
| Прицельная атака: **рука** | 5 |
| Прицельная атака: **нога** | 5 |
| Прицельная атака: **глаз** (крайне сложно, огромный крит-потенциал) | 8 |
| Прицельная атака: **пах** (шанс шока, обездвиживание) | 7 |
| Очередь из автомата (3 выстрела) | 6, точность -15% |
| Полный магазин очередью | 8, точность -30% |
| Перезарядка (обычная) | 3 |
| Перезарядка (перк "Быстрая перезарядка") | 2 |
| Смена оружия из основного слота (не быстрый слот) | 2 |
| Открыть/закрыть дверь | 2 |
| Взять предмет из мира | 2 |
| Использовать аптечку (не быстрый слот) | 4 |
| Заложить мину / взрывчатку | 5 |
| Ближний бой (нож, приклад) | 3 |
| Оглушить (специальный ближний бой, требует навыка) | 5 |
| Толкнуть противника (сбить с ног) | 4 |
| Прикрыться / уйти в укрытие | 2 |

**Правило:** одно действие не может стоить 100% AP. Игрок всегда должен иметь опцию "хоть что-то ещё сделать". Максимальная стоимость одного действия = 8 AP.

## 4.2 Прицеливание в части тела

Ядро тактики. Каждая часть даёт свой профиль риск/награда.

### Шесть целей + профили

| Часть | Мод. точности | Урон | Крит-шанс | Эффект при уроне |
|---|---|---|---|---|
| **Голова** | -25% | ×1.5 | +40% | Крит → потеря сознания 1-2 хода; фатально с некоторым шансом при HP < 30% |
| **Торс** | +0% (базовый) | ×1.0 | +5% | Просто урон HP |
| **Рука** | -10% | ×0.7 | +10% | Крит → сброс оружия; -20% точности жертвы |
| **Нога** | -10% | ×0.7 | +10% | Крит → обездвиживание 1-2 хода; -3 AP жертве |
| **Глаз** | -40% | ×1.2 | +70% | Крит → слепота (жертва теряет 50% точности) на 3-5 ходов |
| **Пах** | -20% | ×0.5 | +25% | Крит → шок 1 ход + огромная потеря морали (для NPC) |

Значения baseline v0.1 — критик и балансный проход тюнят.

### Правила прицельных выстрелов

- Игрок видит расчёт: **финальный шанс попадания** + **шанс крита при попадании** + **предполагаемый урон**.
- Прицельный выстрел **всегда стоит больше AP**, чем обычный.
- Прицельный выстрел **не может** быть очередью — только одиночный.
- Прицельный выстрел из скрытности (стелс) даёт **+2× крит-шанс**.
- Прицельный выстрел в упор (1-2 клетки) даёт **+15% точности**.

### Крит-эффекты

Крит не просто больший урон. У каждой части — свой эффект. Это то, что делает бой тактическим.

- **Голова:** оглушение или смертельный шок при низком HP.
- **Рука:** сброс оружия → жертва тратит 5 AP чтобы поднять, или дерётся кулаками.
- **Нога:** обездвиживание → жертва не может двигаться 1-2 хода.
- **Глаз:** слепота → -50% точности, действует 3-5 ходов.
- **Пах:** шок → пропуск хода + -30% морали в отряде (важно против организованных мародёров).

## 4.3 Формула попадания (базовая)

Читаемая, декомпозируемая, поддающаяся балансу.

```
HitChance = base + skill + weapon + range + cover + posture + status + partMod

где:
  base       = 55%                                       // базовый шанс новичка с рабочим оружием
  skill      = 0..40%                                    // навык оружия (0 при 0 навыке, 40 при 100)
  weapon     = -20..+15%                                 // точность оружия (мосинка +10, самопал -15)
  range      = -30..+15%                                 // расстояние vs оптимальный диапазон оружия
  cover      = -50..0%                                   // укрытие цели (полное -50, частичное -25, нет 0)
  posture    = -10..+10%                                 // поза стрелка (лёжа +10, стоя 0, спринт -10)
  status     = -30..+15%                                 // ранение, страх, шок; трезвость/стимы
  partMod    = зависит от части тела (см. 4.2)
```

Итог **зажимается в 5%..95%**. Даже "гарантированный" выстрел может промахнуться (5% всегда), даже "невозможный" — попасть (5% всегда). Классика жанра, оставляет место для истории.

### Пример расчёта

Ситуация: игрок 5 уровня, "Стрелковое оружие" = 40, стреляет из АКМ (точность +5) на средней дистанции по мародёру в **частичном укрытии**, целится в **голову**, стоит **стоя**, без ранений.

```
base    = 55
skill   = +16      // 40/100 × 40
weapon  = +5
range   = 0        // оптимал
cover   = -25      // частичное укрытие
posture = 0
status  = 0
partMod = -25      // голова
──────────────
Итог    = 26%
```

Крит-шанс при попадании: 5% (базовый) + 40% (голова) = **45%**.

Игрок видит: "26% попасть, 45% крит при попадании, 45-70 урона, крит → 68-105 + оглушение".

Итого: с одной стороны — рискованно, с другой — если попадёт, скорее всего критом. Осознанный выбор.

## 4.4 Урон

### Формула

```
Damage = weaponBaseDamage × partModifier × critMultiplier − armor + statusMods
```

- **weaponBaseDamage:** диапазон (например ПМ: 15-25).
- **partModifier:** см. таблицу 4.2 (0.5 - 1.5).
- **critMultiplier:** обычный × 1.0, крит × 1.5-2.5 в зависимости от оружия и части тела.
- **armor:** каждая часть тела имеет свою броню (шлем защищает голову, бронежилет — торс). Может быть до 80% редукции у топовой брони.
- **statusMods:** кровотечение, ожог, отравление — над временем.

Урон **никогда не может быть ниже 1** при попадании (даже в топ-броню). Иначе игрок фрустрируется от "0 урона".

### Грейз (задел)

Если попадание меньше урона брони, но выстрел был "почти" (в пределах 15% попадания), — считается **грейз**: 25% базового урона, никаких дополнительных эффектов. Даёт игроку чувство, что "я хоть что-то сделал".

## 4.5 Инициатива и порядок ходов

Простая система, никакой d20-магии.

### Расчёт инициативы

```
Initiative = 10 + Perception + Agility + weaponSpeedMod + randomJitter(0..3)
```

- **Perception, Agility:** атрибуты 1-10 (см. раздел 05).
- **weaponSpeedMod:** пистолет +3, штурмовая винтовка +1, снайперка -2.
- **randomJitter:** маленький разброс, чтобы бои с одинаковыми участниками не были идентичны.

Порядок — по убыванию Initiative. Раз посчитано — не пересчитываем в течение боя.

### Действия в очереди (reserve actions)

Механика "оставить AP для реакции" (как **Overwatch** в XCOM).

- Игрок может закончить ход **не потратив все AP** и объявить: "готовлю выстрел".
- В следующем противнике-ходу, если враг двигается в поле зрения — игрок автоматически стреляет из зарезервированных AP.
- Точность зарезервированного выстрела: -15% (быстро прицелился).

Это добавляет тактики: обороняться в укрытии → зарезервировать → стрелять по всем, кто пытается подойти.

## 4.6 Укрытия и позиционирование

### Три уровня укрытий

- **Полное укрытие** (стена, полностью загораживает противника): **-50% попадания**, но стрелок сам не может стрелять "сквозь" — надо выйти.
- **Частичное укрытие** (ящики, столы, углы): **-25% попадания**, стрелок может стрелять с частичным штрафом.
- **Нет укрытия:** 0.

Игрок видит зоны укрытий на гриде **до входа в клетку**. Наведение мышью → подсветка "здесь -25%".

### Позы стрелка

- **Стоя:** обычная точность.
- **Присед:** +5% точности, -1 AP к следующему действию (нужно вставать).
- **Лёжа:** +10% точности, -3 AP чтобы встать (медленно), нельзя двигаться. Хорошо для снайперки.
- **Спринт (только что бежал):** -10% точности следующего выстрела.

### Line of Sight (LoS)

- Простая система: если между стрелком и целью **нет полного укрытия** — можно стрелять. Если полное укрытие на пути — нет.
- Частичные препятствия (частокол, дым) — снижают точность (-10..-30%), но не блокируют.
- Дым (гранаты, огонь) — источник -25% точности для всех, кто стреляет сквозь.

## 4.7 Стелс и несмертельные тактики

Столп 1 Vision + идеи из Cold Zero.

### Обнаружение

- У каждого NPC есть **радиус обнаружения** (зависит от Perception, освещения, шума).
- Игрок в скрытности видит этот радиус на карте.
- Шаги, стрельба (без глушителя), взрыв — увеличивают радиус временно.

### Скрытая атака

- Первый выстрел / удар в скрытности: **+2× крит-шанс, +50% урона**.
- С глушителем: выстрел не разрушает скрытность, если жертва падает от одного удара.
- Ближний бой в скрытности → **оглушение** (несмертельно) — жертва без сознания N ходов.

### Несмертельные тактики

- Оглушение (специальный ближний бой) → жертва в отрубе, можно связать.
- Прицельный выстрел в **ногу** → жертва падает, но не умирает.
- **Награда за stealth-прохождение локации:** +50% XP, шанс на "чистый" лут (тела не тронуты).

Из Cold Zero: игрок должен ощущать, что стелс — реальная альтернатива, не проигрышный путь.

## 4.8 Мораль и страх (для NPC)

Простая, но добавляет тактики.

- Каждый враг имеет **уровень морали** (0-100).
- Понижение морали:
  - Смерть союзника рядом: -20 (обычный), -40 (лидер группы).
  - Крит в голову союзника: -15.
  - Пах-крит союзника (шок): -30 (визуально ужасно).
  - Взрыв рядом: -10.
  - Игрок в невидимости атакует незамеченно: -5.
- Эффекты низкой морали:
  - < 40: враг пытается уйти в укрытие, стреляет реже.
  - < 20: враг может **бежать** от боя, если у него есть куда бежать.
  - 0: враг сдаётся (можно взять в плен, обчистить, отпустить).

Это создаёт возможность **выиграть бой без убийств** — тактика "сломать первого = обратить всех в бегство".

## 4.9 Смерть героя в бою

Ключевой момент: смерть **не** = загрузка сейва. Смерть = лорный респавн (см. Vision v0.2, столп 5 + раздел 13).

### Что происходит

1. HP героя опускается до 0.
2. Короткая cutscene: "Артефакт активируется..." (2-3 секунды с анимацией).
3. Герой возрождается в **резервной капсуле на базе**.
4. Применяются штрафы:
   - **-20% опыта** до следующего уровня (не текущий уровень!).
   - **-1 случайный редкий ресурс** из инвентаря + **-30% обычных ресурсов**.
   - **+6 игровых часов** проходит в мире (может провалить активную ежедневку).
   - **-10 энергии** для следующей вылазки.
   - **Лорный шрам:** случайный "фрагмент воспоминания" исчезает (флэйвор-текст в дневнике). К концу игры их будет много.
5. Оружие/броня на герое **не теряются** (иначе — унижение).
6. Игрок оказывается на базе, может отдышаться, перегрупироваться, снова выйти.

### Что происходит в боевой сцене

- Враги остаются в мире. Если герой возвращается в ту же локацию — тела/лут на своих местах, но враги ушли или заняли позиции (в зависимости от типа зоны).
- Основной сюжетный NPC / босс — **не** сбрасывается. Если игрок был близко к победе и умер — он может вернуться и добить (без потери его HP).

Это исключает "фарм смерти" (спам смерти чтобы сбросить бой), но и не наказывает за неудачный бой чрезмерно.

## 4.10 Специальные механики (v0.1 короткий обзор — детали в разделе 06)

### Оружейные особенности

- **Осечка:** самопалы и старое оружие могут дать осечку (шанс 5-15% в зависимости от состояния). Осечка тратит ход, требует 3 AP на "прочистить".
- **Заклинивание:** очередями. Полный магазин на очередь → 20% шанс заклинить → 5 AP на прочистку.
- **Износ:** каждый выстрел изнашивает оружие на 0.5%. При износе >50% начинают падать точность и шанс осечки. При 0% — оружие ломается (можно починить на базе).

### Модификации

- Глушитель: -20% дальнобойности, -10% точности на дальних, +40% скрытности выстрела.
- Коллиматор: +5% точности на средних, +10% в упор.
- Расширенный магазин: +30% ёмкости, но +1 AP на смену.
- Приклад-обвес: -1 AP на прицельный выстрел (быстрее целится).

Детали и рецепты — раздел 06.

## 4.11 UI боя (что видит игрок)

Каждое поле должно быть читаемым за 2 секунды.

- **Верх экрана:** порядок ходов (portrait-иконки), текущий ход подсвечен.
- **Персонаж:** HP-бар, статус (кровотечение, шок и т.д.), AP-индикатор (10 сегментов).
- **Наводя курсор на клетку:** подсветка укрытий (зелёное = полное, жёлтое = частичное, красное = открыто).
- **Наводя курсор на цель (враг):** показывает
  - HP цели
  - Расстояние
  - Финальный шанс попадания (голова / торс / нога — все три)
  - Шанс крита при попадании
  - Предполагаемый урон
- **Нижний экран:** быстрый слот (аптечка, стим, граната), кнопка "закончить ход".
- **Мобильная версия:** большие кнопки, свайп-меню действий.

## 4.12 Что не входит в MVP

Классический список "не сейчас, позже":

- ❌ Компаньоны в бою (МVP — только герой; союзные NPC могут быть скриптованы в отдельных миссиях).
- ❌ Управление отрядом (JA2-стиль). MVP — соло.
- ❌ Тяжёлое оружие (гранатомёты, огнемёты) — post-MVP.
- ❌ Сложные атмосферные эффекты (дождь, ветер, влияющие на баллистику). MVP — только дым и туман.
- ❌ Полностью разрушаемая среда. MVP — точечные интерактивные объекты (взрыв двери, разрушение слабой стены).
- ❌ Гиперреалистичные ранения (ампутации, слепота на всю жизнь). MVP — статусы длятся до конца боя + краткое время после.

## 4.13 Открытые вопросы для критика (Combat Critic — следующий)

- **CC1** Балансна ли AP-стоимость прицельных выстрелов? Не слишком ли дорого 6-8 AP на голову?
- **CC2** Формула попадания — читаема ли игроку? Не слишком ли много переменных?
