# design-data

Входные и выходные данные инструментов, которые считают баланс, производительность и QA. Это **не** игровой контент: runtime не читает ни один файл из этого каталога. Игровой контент живёт в `code/public/config/` по контракту [`docs/23-data-contracts-and-content-pipeline.md`](../docs/23-data-contracts-and-content-pipeline.md).

**Статус на 22 августа 2026:** каталог создан тикетом `W0-03` и пуст. Ни одного отчёта ещё не сгенерировано, потому что симулятор баланса (`W3-01`), perf-харнесс (`W1-06`) и ручная mobile QA (`W2-06`) не реализованы.

## Структура

| Подкаталог | Содержимое | Вводится |
|---|---|---|
| `balance/` | отчёты симулятора баланса (`*.json`), сырые прогоны (`*.csv`) | `W3-01` |
| `perf/` | отчёты производительности из браузерного харнесса (`*.json`) | `W1-06` |
| `qa/` | отчёты ручных QA-прогонов по скриптам MS-01…MS-06 (`*.md`) | `W2-06`, `W1-05` |

Подкаталог создаётся тем тикетом, который первым пишет в него файл. Пустые подкаталоги заранее не создаются.

## Правила именования

- `balance/<дата>-<арена>-<seed>.json` — например, `2026-08-25-relay-station-12345.json`.
- `perf/<дата>-<коммит>.json` — например, `2026-08-25-3f87b80.json`.
- `qa/<дата>-manual-mobile.md` — например, `2026-08-25-manual-mobile.md`.

Дата — ISO `YYYY-MM-DD`. Коммит — короткий SHA. Только строчные буквы, цифры и дефисы.

## Правила содержимого

1. Формат отчёта симулятора задан в [`docs/23`](../docs/23-data-contracts-and-content-pipeline.md) §8 и обязателен: без полей `commit`, `seed`, `runs` отчёт невоспроизводим и не принимается.
2. Каждый отчёт фиксирует seed и commit. Отчёт, который нельзя воспроизвести, не является основанием для изменения баланса.
3. Отчёт — это измерение, а не решение. Изменение числа в игре делается отдельным коммитом со ссылкой на отчёт.
4. Отчёт ручной QA обязан называть устройство, ОС, браузер и сценарий. Формулировки вида «проверено на мобильном» без этих полей запрещены правилом 5 из [`docs/22`](../docs/22-developer-work-packages.md) §«Общие требования».
5. Файлы этого каталога не влияют на сборку и не импортируются кодом.
